使用说明
基本用法
  1. 上传 SRT/VTT 字幕文件，或直接在文本框输入内容（每行一句）
  2. 选择音色（支持 75 种语言 322 个音色，可用语言筛选）
  3. 按需调整语速和音量
  4. 点击「开始生成」，等待处理完成
  5. 在线试听，确认无误后下载 MP3
字幕格式说明

支持标准 SRT 和 VTT 格式：

1
00:00:01,000 --> 00:00:04,000
第一句字幕内容

2
00:00:04,000 --> 00:00:08,000
第二句字幕内容

序号和时间戳会自动跳过，只把文字内容转为语音。语音按时间戳间隔排列，不会截断。

制作 YouTube 多音轨视频

用不同音色生成多语言音频后，用 ffmpeg 合并：

ffmpeg -i 视频.mp4 -i 中文.mp3 -i 英语.mp3 \
  -map 0:v -map 1:a -map 2:a \
  -c:v copy -c:a aac \
  -metadata:s:a:0 language=chi \
  -metadata:s:a:1 language=eng \
  输出.mp4

然后在 YouTube Studio 上传时选择多音轨。
